# GST Trip Bill Maker

A web application for generating and printing professional GST invoices and itineraries for honeymoon trip packages.

## Features
- Create and edit client invoices with destination details.
- Automatic calculation of CGST, SGST, and IGST.
- Itemized billing for packages and add-ons.
- Customizable company details and GSTIN.
- Save, view, delete, and print client invoices.
- Offline support and capability to be added to the home screen (PWA).
- Local storage for data with Backup/Restore options in JSON format.

## Technology
- Pure HTML, CSS, and Vanilla JavaScript.
- No build steps or external dependencies required.
- Mobile-first responsive design.

## How to run
Simply open `index.html` in your web browser.
