# Gunjan Boutique Showcase

A luxury fashion boutique website showcasing ethnic and designer collections with direct WhatsApp ordering for customers in Mumbai.

## Features
- Stunning luxury hero banner with seasonal collection highlights
- Filterable category grid for Lehengas, Sarees, Kurtis, and Indo-Western wear
- Product detail view with high-res image placeholder and description
- Direct 'Order via WhatsApp' button pre-filling product details
- About Us section highlighting custom tailoring and designer fittings
- Customer reviews and testimonials carousel
- Contact and Mumbai store location information
- Mobile-first, responsive design with luxury black and gold theme
- PWA ready (installable)

## Technical Details
- Built with HTML, CSS, and Vanilla JavaScript
- No build steps or external dependencies
- Hosted on GitHub Pages
- Assets are handled inline or via SVG placeholders to work fully offline after the first load.
